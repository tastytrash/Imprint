# Imprint

A client-side mod that adds vanilla-style footprint particles. Shows footprints for you, other players, and mobs as they walk around.

## Features
![Config menu](https://cdn.modrinth.com/data/cached_images/bbfeefb4612c4b0ba27e99c6f58b061a736555cc.png)
- Configurable footprint color and size
- Toggle footprints for other players and mobs
- Adjustable footprint lifetime
- And more

## Dependencies

Fabric API and Cloth Config are required.

## Configuration

Access settings via Mod Menu or edit the config file.

## Compatibility

Client-side only. Works on any server.
