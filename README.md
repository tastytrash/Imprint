#### A lightweight client-side mod that brings footprint particles to Minecraft, designed to blend with vanilla aesthetics.
## Features

*   Footprints for players and mobs with mob-specific spacing/timing
*   Dust, snow, and leaf particles on certain blocks
*   Configurable color, size, alpha, and lifetime
*   Client-side only
*   Performance options
*   And more

![Config menu](https://cdn.modrinth.com/data/cached_images/a313f913325d7f8eec24ff4d0fead018bb48c76f.gif)

## Dependencies
Fabric API (when using fabric), Cloth Config

## Configuration

Access config via Mod Menu (for fabric) or edit the config file.
